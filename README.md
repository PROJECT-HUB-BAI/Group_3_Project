# GUI Based Life Tracker Game

## Introduction

The GUI Based Life Tracker Game is a C application that turns everyday responsibilities into role-playing game quests. Players create an account, complete real-life tasks, earn experience points (XP), advance through levels, and use points to obtain rewards. The project uses structures, functions, conditional statements, loops, and file handling to manage gameplay and retain player progress.
